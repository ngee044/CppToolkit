# CppToolkit
A versatile collection of C++ modules and utilities designed to streamline and enhance personal projects. From core functionalities to advanced features, cppToolkit is your go-to resource for efficient C++ development.

## Features
- **Modular Utilities**: Self-contained classes/functions for common tasks.
- **Modern C++17**: Leveraging language features (e.g., `std::optional`, `std::variant`, `auto`).
- **CMake Build System**: Consistent build configuration across multiple platforms.
- **Extensible**: Easily integrate new modules or adapt existing ones.
