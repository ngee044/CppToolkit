## Basic Coding Convention

This document introduces the basic coding conventions.

We use C++ up to version 17.

External libraries are managed using **vcpkg**, and we ensure cross-platform compatibility on **macOS/Linux/Windows**.

The project is managed using **CMake**. It is based on an **MSA (Microservice Architecture)** structure, modularized into large and small units and used in the form of libraries, while keeping the **Main** clean and minimal.

Below are the code conventions:

- All **functions** must be written in **lowercase snake_case**.
- **Class, Struct names** must be written in **PascalCase**.
- **Member variables (Class, Struct)** must be distinguished by appending an underscore (`_`) at the end and written in **lowercase snake_case**.

Avoid using abbreviated names for variables. Do not prefix variable or class names with type hints such as `cMyClass` or `inum_count_`. Also, use **trailing return types**.

For **boolean** types, return a message using `std::tuple<bool, std::optional<std::string>>` to allow the programmer to understand the error cause.

Use **newline braces**.

```
if (true)
{
}
```

Do **not** use:

```
if (true) {

}
```

Even in one-liners, always use braces.

The default **tab size is 4**, and **indentation must be done with tabs**.
